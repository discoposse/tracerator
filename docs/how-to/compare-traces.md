# How to compare traces

Open http://localhost:8008/compare.

Load up to five `manifest.json` or `replay_result.json` files, or pick saved workspace runs.

The page draws a shared ISL distribution, a KPI summary, and a comparison table. Export HTML or PNG from the page. Use the browser print dialog for PDF.

Compare runs that share a question: same source with two reuse biases, or two sources at the same scale. Mixed questions make the table noisy.
